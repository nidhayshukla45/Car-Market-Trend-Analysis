# Car Market Trends Analysis

This project analyzes the CarDekho vehicle dataset to understand trends in used vehicle prices and depreciation.

## Project Overview

The dataset contains information about vehicles such as:

- Vehicle Name
- Year
- Selling Price
- Present Price
- Kilometres Driven
- Fuel Type
- Seller Type
- Transmission
- Owner

The project uses Python to analyze the dataset and identify patterns related to vehicle prices, depreciation, and market trends.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Data cleaning and exploration
- Vehicle price analysis
- Depreciation analysis
- Car and two-wheeler comparison
- Fuel type analysis
- Seller and transmission analysis
- Correlation analysis
- Data visualization using pie charts, bar charts, scatter plots, and heatmaps

## Files

- `Car_Market_Trends_Analysis.ipynb` - Complete data analysis notebook
- `1776311302-P3-Car Market Trends Analysis with Car Dekho Data.csv` - Dataset used for the analysis
